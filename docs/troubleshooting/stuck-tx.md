# Troubleshooting a Stuck Transaction

## First, identify what is actually stuck

- Is it stuck on the sending platform, or on chain?
- Do you have a transaction ID?

## Common causes

- Low fee settings
- Network congestion
- Wallet broadcast issues

## What to do

- Confirm the transaction exists on a block explorer
- If it is unconfirmed, wait before retrying
- For wallets that support it, consider fee bump features where applicable

## What not to do

- Do not send another transfer to the same address assuming it will fix it
- Do not trust random DMs claiming they can recover funds
