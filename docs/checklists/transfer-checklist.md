# Transfer Checklist

Use this checklist before sending any crypto transfer.

## Asset and amount

- Asset name is correct
- Amount is correct
- Fees are understood

## Network

- Sending network selected
- Receiving network supports it
- Memo or tag requirements checked

## Address

- Address copied from trusted source
- First and last characters verified
- Test transfer completed for large amounts

## After sending

- Transaction ID saved
- Explorer status checked
