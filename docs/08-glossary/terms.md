# Glossary: 2026 Technical Terms

Precision in language prevents errors in execution.

| Term | Definition |
| :--- | :--- |
| **Account Abstraction (AA)** | A technology (ERC-4337) that turns your wallet into a smart contract, allowing for social recovery and custom security rules. |
| **Bridge** | A protocol that allows the transfer of assets or data between two different blockchain networks. |
| **CEX** | Centralized Exchange (e.g., Binance, Coinbase, Kraken). |
| **DEX** | Decentralized Exchange (e.g., Uniswap, PancakeSwap). |
| **EOA** | Externally Owned Account. A traditional wallet like MetaMask that is controlled directly by a private key/seed phrase. |
| **Finality** | The point at which a transaction is considered irreversible on the blockchain. Different chains have different times to finality (e.g., Solana is seconds, Ethereum is ~15 mins). |
| **Gas** | The fee paid to validators to process your transaction. Paid in the "Native Token" of the chain (ETH for Ethereum, TRX for Tron). |
| **L2 (Layer 2)** | A network built on top of a Layer 1 (like Ethereum) to provide faster and cheaper transactions (e.g., Arbitrum, Optimism). |
| **MEV** | Maximal Extractable Value. The profit validators/bots make by manipulating the order of transactions. |
| **Mempool** | The "waiting room" where transactions sit before being picked up by a validator. |
| **Nonce** | A "Number used Once." A counter in your wallet that ensures transactions are processed in the correct order and prevents double-spending. |
| **Passkey** | A cryptographic credential that uses your device's biometric security (FaceID) to sign transactions, replacing the need for a seed phrase. |
| **Reorg (Chain Reorganization)** | When a blockchain "forks" and one path is abandoned. Transactions on the abandoned path may be reverted. Always wait for multiple confirmations for large transfers. |
| **Slippage** | The difference between the expected price of a trade and the price at which the trade is executed. |
| **TXID / Hash** | The unique "Receipt" ID for a transaction. |
