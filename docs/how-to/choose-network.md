# How to Choose the Right Network

Choosing the wrong network is one of the fastest ways to lose funds.

## Step 1: Identify the asset

Make sure the asset matches exactly, for example USDT is not the same as USDC.

## Step 2: Identify the network on the sending side

Many assets exist on multiple networks. For example stablecoins may exist on Ethereum, Tron, BNB Chain, Polygon, and more.

## Step 3: Match the network on the receiving side

The receiving address must support the same network.

## Step 4: Use a test transfer

For large amounts, send a small test amount first.

## Practical notes

- If a platform shows multiple network options for the same asset, do not guess.
- If you are unsure, stop and verify.
