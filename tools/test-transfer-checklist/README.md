# Test Transfer Checklist

For any transfer over **$500 USD** (or equivalent), a test transfer is the only 100% effective insurance policy.

## Step 1: The Initial Configuration

- [ ] Select the asset and the network on the sender side.
- [ ] Paste the recipient address.
- [ ] Verify the address first/middle/last characters visually.

## Step 2: The Small Amount

- [ ] Send the **minimum allowed** by the sender (e.g., $10 or $20).
- [ ] Note that you will pay gas fees *twice* (once for the test, once for the final). This is a "safety tax."

## Step 3: Verification of Receipt

- [ ] Wait for the transaction to show "Confirmed" or "Success" on the block explorer.
- [ ] **Crucial:** Log in to the receiving wallet/exchange and verify the funds are actually **available and credited**.
- *Just because it shows "Success" on the explorer doesn't mean the exchange has credited it yet.*

## Step 4: The Main Transfer

- [ ] Once the test is confirmed in the *receiving account*, go back to the sender.
- [ ] **DO NOT** re-type the address. Use the "Recents" or "Address Book" entry that you just successfully used.
- [ ] Send the remaining balance.

## When to SKIP a test transfer

- **Never.**
- Even if you are in a rush, a lost $5,000 takes much longer to "fix" (usually forever) than a 10-minute test transfer takes to complete.

---
**Authority Tip:** In high-congestion periods, verify that the gas price hasn't spiked between your test and your main transfer. A "Pending" main transfer after a successful test transfer is a common source of user anxiety.
