# Contributing

Thanks for helping improve this guide.

## What to contribute

- Fix inaccuracies
- Add clearer explanations
- Add new wallet safety tips
- Add network notes for common assets
- Improve checklists

## How to contribute

1. Open an issue describing the change
2. Submit a PR with a clear title and short summary
3. Keep language neutral and tool agnostic
4. Avoid promotional content

## Style

- Short sentences
- Practical steps
- Prefer examples and checklists
