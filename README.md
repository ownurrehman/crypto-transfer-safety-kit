# Crypto Transfer Safety Kit

Practical guides to help you send crypto safely and avoid common mistakes like wrong networks, incorrect addresses, and phishing traps.

## Contents

- Network basics and common token networks
- How to verify addresses and transaction status
- Safety checklists for wallets and exchange accounts
- Troubleshooting for stuck or pending transfers

## Quick start

Read these first:

- docs/how-to/choose-network.md
- docs/how-to/verify-address.md
- docs/checklists/transfer-checklist.md

## Principles

- Neutral and tool agnostic guidance
- Focus on preventing irreversible errors
- Clear steps and simple explanations
